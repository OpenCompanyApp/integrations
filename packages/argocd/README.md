# Argo CD Integration

Generated Argo CD API tools for OpenCompany and KosmoKrator hosts.

Source Swagger document: <https://raw.githubusercontent.com/argoproj/argo-cd/master/assets/swagger.json>

The package exposes the official Argo CD server API for accounts, applications, application sets, certificates, clusters, GPG keys, notifications, projects, repository credentials, repositories, sessions, settings, streams, write repositories, and version metadata. Tools use bearer-token authentication when configured and preserve the original hand-written slugs for common application, project, repository, and user operations.
