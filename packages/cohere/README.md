# Cohere Integration

Cohere tools for OpenCompany agents.

## Tools

- `cohere_chat`
- `cohere_embed`
- `cohere_rerank`
- `cohere_tokenize`
- `cohere_detokenize`
- `cohere_list_models`
- `cohere_get_model`
- `cohere_create_embed_job`
- `cohere_list_embed_jobs`
- `cohere_get_embed_job`
- `cohere_cancel_embed_job`
- `cohere_create_dataset`
- `cohere_list_datasets`
- `cohere_get_dataset`
- `cohere_delete_dataset`
- `cohere_get_dataset_usage`
- `cohere_create_audio_transcription`
- `cohere_classify`

## Credentials

Configure `api_key`. Optional fields:

- `client_name` sends `X-Client-Name`.
- `url` overrides the API base URL, defaulting to `https://api.cohere.com`.
