# Deepgram Integration

Deepgram REST API tools for OpenCompany agents.

## Covered

- Prerecorded speech-to-text by URL and raw audio bytes
- Text Intelligence via `/read`
- Text-to-speech via `/speak`
- Public and project model metadata
- Projects, project keys, balances, usage breakdown, and project requests

WebSocket live transcription, live TTS, and Voice Agent APIs are not exposed by this JSON tool package yet.
