# Directus Integration

Generated Directus REST API tools for OpenCompany and KosmoKrator hosts.

Source OpenAPI document: <https://unpkg.com/@directus/specs@13.0.0/dist/openapi.json>

The package exposes the official Directus API surface for activity, assets, authentication, items, collections, files, flows, permissions, roles, schema, users, utilities, and content versions. Tools use bearer-token authentication when configured and preserve the original hand-written slugs for common item and collection operations.
