# Helicone Integration

Helicone REST API and AI Gateway tools for OpenCompany agents.

## Covered

- Request query via `/v1/request/query-clickhouse`
- Request lookup via `/v1/request/query-ids` and `/v1/request/{requestId}`
- Request feedback via `/v1/request/{requestId}/feedback`
- User metrics query endpoints
- AI Gateway `/v1/models`, `/v1/chat/completions`, and `/v1/responses`
