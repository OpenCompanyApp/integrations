# Neon Integration

Generated Neon API tools for OpenCompany and KosmoKrator hosts.

Source OpenAPI document: <https://neon.com/api_spec/release/v2.json>

The package exposes the official Neon API surface for API keys, projects, branches, databases, roles, compute endpoints, operations, permissions, Neon Auth, organizations, consumption, billing, transfers, and user metadata. Tools use bearer-token authentication and preserve the original common slugs for project, branch, database, and current-user operations.
