# Pipedrive Integration

Generated from Pipedrive's official v1 and v2 OpenAPI schemas.

Sources:

- `https://developers.pipedrive.com/docs/api/v1/openapi.yaml`
- `https://developers.pipedrive.com/docs/api/v2/openapi.yaml`

This package exposes CRM operations for deals, persons, organizations, activities, products, leads, projects, notes, files, webhooks, goals, fields, pipelines, stages, users, search, and related account resources.

The integration uses the official `x-api-token` header. v1 tools use `/v1`; v2 tools are prefixed with `pipedrive_v2_` and use `/api/v2`.
