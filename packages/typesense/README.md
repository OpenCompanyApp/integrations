# Typesense Integration

Generated from Typesense's official OpenAPI schema.

Source: `https://raw.githubusercontent.com/typesense/typesense-api-spec/master/openapi.yml`

This package exposes the Typesense REST API for collections, documents, search, API keys, aliases, synonym sets, curation sets, analytics rules, presets, stopwords, overrides, health/debug endpoints, and cluster operations.

Requests use the `X-TYPESENSE-API-KEY` header and a configurable Typesense node or cluster URL.
